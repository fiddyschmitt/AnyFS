The first release. AnyFS presents anything as a file system: a *source* plugin turns some system
into a tree of files, a *mount provider* exposes that tree to the operating system or the network,
and a *collection* groups sources and decides how it is mounted. One self-contained executable per
OS, with a window or headless (`anyfs serve`, `anyfs status`).

**Sources**: Mirror (local folders, drives and, on Windows, UNC shares) and SSHFS (a folder on any
SSH server: keys or passwords, two-factor prompts, host keys pinned on first use).

**Mounts**: WinFsp (`\\anyfs\<collection>` on Windows; the tile installs the driver if it is
missing), SMB on every OS through the bundled portable-smb-server 0.4.1, FUSE on Linux, WebDAV,
FTP, and HTTP with directory pages and resumable downloads.

**Plugins**: write your own against the `AnyFS.Sdk` package (attached, with `AnyFS.Sdk.Testing`),
drop the DLL into `plugins/`, and `anyfs plugin check <dll>` says whether it loads in the trimmed
host. See `docs/plugin-authoring.md`.

**Tested** on Windows, Linux and macOS: unit and GUI tests, and an end-to-end lab of Debian,
Windows 11 and macOS machines that exercises every mount from every machine.

**Downloads**: a zip for Windows and a tar.gz for Linux and macOS, each with the executable, the
licence and the docs; `SHA256SUMS.txt` lists their sums. Settings live beside the executable when
that folder is writable, otherwise in the user's config folder (`docs/settings-format.md`).

**Not yet**: a macOS `.app` bundle and NFS. SMB from a Mac to its own anyfs runs at about 10 MiB/s.

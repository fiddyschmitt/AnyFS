A maintenance release: the bundled SMB server moves to portable-smb-server 0.4.2.

**SMB**: portable-smb-server 0.4.2 is a performance release of the server behind the SMB mount:
faster message signing, pipelined writes, one gathered write per response and zero-copy reads. Its
SMB behaviour and AnyFS's contract with it are unchanged, so nothing changes in the settings or in
what a client sees. In the lab, a Mac reading from its own anyfs over SMB now measures over
300 MiB/s on a 200 MiB file (the 0.1.0 notes said about 10); the Linux and Windows figures are as
before.

**Tested** as 0.1.0 was: unit and GUI tests on Windows, Linux and macOS, the trimmed smoke test,
and the end-to-end lab's SMB rows on the Windows, Linux and macOS hosts from every machine.

**Downloads**: one executable per OS, nothing to unpack: `anyfs-win-x64.exe`, `anyfs-linux-x64`,
`anyfs-linux-arm64`, `anyfs-osx-arm64` (Apple silicon) and `anyfs-osx-x64` (Intel); on Linux and
macOS run `chmod +x` on it first. `SHA256SUMS.txt` lists their sums.

**Not yet**: a macOS `.app` bundle and NFS.
